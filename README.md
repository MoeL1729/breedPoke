# POkegotchi 2.2

알에서 만난 친구와 먹고, 쉬고, 전투하는 픽셀 포켓몬 팬 게임입니다. 이제 야생 포켓몬을 포획하여 최대 3마리까지 키웁니다. 빌드 없이 GitHub Pages에서 실행하는 HTML/CSS/JavaScript 앱입니다.


## 2.2 밸런스·3세대 스타터 추가

- 희귀 3종은 합계 15% → 6%, 일반 스타터는 합계 85% → 94%. 일반 종이 늘어나 개별 확률은 약 2.4103%입니다.
- 새 알은 피카츄 대신 피츄. 친밀도 220 이상에서 레벨업하면 피카츄, 이후 천둥의돌로 라이츄가 됩니다. 기존 피카츄와 저장 경험치는 그대로 유지합니다.
- 승리 경험치를 20% 줄이고 소수점은 버립니다. 상대 레벨 7: 187 → 149, 레벨 12: 472 → 377. 포인트는 기존 80 P입니다.
- 3세대에서 처음 등장한 3단계 진화 계열 14종을 알 후보에 추가했습니다. 3세대 진화형까지 포함하며 기술·타입·능력치는 기존 HGSS 기준입니다. 랄토스는 가디안 경로를 지원하며 4세대 추가 분기인 엘레이드는 이번 추가 범위에 포함하지 않습니다. 야생 상대는 기존 1세대 146종을 유지합니다.
- 이로치 4%, 파티 3마리, 기술 4칸, 도구와 포획 규칙은 유지합니다.

이번에는 피츄·3세대 포켓몬 45종의 일반/이로치 앞뒤 이미지 **180장**이 추가됩니다. 반드시 `assets/sprites`와 `assets/shiny`도 함께 업로드하세요. 사용자 배포 경로에 맞춰 이로치는 **assets 바로 아래 shiny**를 사용합니다. 과거 `assets/sprites/shiny` 경로만 있다면 `assets/shiny`로 이동하거나 최신 ZIP의 해당 폴더를 업로드해야 합니다.

## 2.1 추가 도구

전투용 도구 36종을 추가했습니다. 전체 목록·가격·효과·참고 링크는 `data/items.json`에 기록했습니다. 실제 상점/전투는 `engine.js`의 ITEMS를 사용하며 JSON은 같은 목록에서 추출한 배포 스냅샷입니다.

| 분류 | 추가 내용 |
|---|---|
| 공격 강화 | 힘의머리띠, 박식안경, 달인의띠, 생명의구슬 |
| 자동 회복·치료 | 조개껍질방울, 자뭉열매, 리샘열매, 유루열매 |
| 9세대 도구 | 클리어참, 은밀망토 |
| 타입 강화 17종 | 실크스카프·검은띠·예리한부리·독바늘·부드러운모래·딱딱한돌·은빛가루·저주의부적·금속코트·목탄·신비의물방울·기적의씨·자석·휘어진스푼·녹지않는얼음·용의이빨·검은안경 |
| 회복·치료약 9종 | 고급상처약, 풀회복약, 회복약, 해독제, 화상치료제, 얼음상태치료제, 잠깨는약, 마비치료제, 만병통치제 |

기존 도구는 HGSS 효과 기준(고급상처약 HP 200), 클리어참·은밀망토는 9세대 효과를 현재 엔진에 적용합니다. 은밀망토는 현재 구현된 공격 기술의 추가 상태이상/능력치 변화를 막으며 변화기는 막지 않습니다. 원작 전체 특성·풀죽음·날씨 시스템은 추가하지 않았습니다. 열매는 지닌 도구로 자동 발동하며 가방에서 먹이는 기능은 없습니다. 금속코트의 전투용 상품과 기존 진화용 소비 상품은 별도입니다. 가격은 게임 밸런스용입니다.

2.0을 사용 중이면 assets 변경은 없습니다. 최신 ZIP의 코드와 data를 덮어쓰면 됩니다. 더 오래된 버전에서 업데이트할 때는 assets도 포함하세요.

## 기존 주요 기능

- **이로치:** 알과 야생 등장 시 독립 추첨. **4%**입니다. 알·야생 등장마다 독립 추첨하며 기존 포켓몬의 색상을 다시 추첨하지 않습니다. 포획·진화·저장에도 색상이 유지됩니다.
- **세 마리 육성:** 같은 종도 각각 키울 수 있습니다. 목록에서 돌볼 친구를 선택하며 전투 중 교체는 한 턴을 사용합니다. 3마리가 있으면 추가 포획할 수 없고 PC 보관함은 없습니다.
- **포획:** 종별 포획률, 현재/최대 HP, 볼, 상태이상을 HGSS 공식에 넣어 계산한 최종 성공 확률을 1.1배, 최대 100%로 적용합니다. 실패하면 상대가 행동합니다. 성공하면 전투가 끝나며 포획한 친구의 전투 상태이상은 해제됩니다.
- **데미지 표시:** 효과가 굉장하면 빨강, 반감이면 파랑, 무효면 보라·회색과 ‘효과 없음’ 문구를 표시합니다. 색상과 설명을 함께 제공합니다.
- **상점과 가방:** 전투 보상 포인트로 볼·회복약·지닌 도구·진화 도구·교환권을 구매합니다. 전투 중 회복약 사용은 한 턴을 사용합니다.
- **저장 호환:** 이전 저장을 자동 변환하며 레벨·기술·포인트 등 육성 진행을 이어갑니다. 고오스가 저주를 배운 뒤 발생했던 화면 오류와 모바일 HP창 겹침 수정도 포함합니다.

## 상점

가격은 이 게임의 밸런스용 설정입니다.

| 도구 | 가격 | 효과 |
|---|---:|---|
| 몬스터볼 | 40 P | 포획 볼 배율 1 |
| 수퍼볼 | 80 P | 포획 볼 배율 1.5 |
| 하이퍼볼 | 120 P | 포획 볼 배율 2 |
| 상처약 | 60 P | HP 20 회복 |
| 좋은상처약 | 120 P | HP 50 회복, 4세대 기준 |
| 선제공격손톱 | 600 P | 같은 기술 우선도 안에서 20% 확률로 먼저 행동 |
| 먹다남은음식 | 1,000 P | 턴 종료 시 최대 HP의 1/16 회복, 최소 1 |
| 오랭열매 | 30 P | HP가 절반 이하일 때 10 회복 후 소모 |
| 진화 도구 | 각 300 P | 도감에 수록된 해당 진화 조건에 사용 |
| NPC 교환권 | 150 P | 교환 진화 1회, 필요한 진화 도구는 별도 |

포켓몬마다 지닌 도구는 한 개입니다. 상처약은 가방에서 직접 사용하며 지니게 할 수 없습니다. 전투 밖에서 도구를 교체합니다. 기절한 포켓몬은 회복약으로 부활하지 않으며 밥·잠으로 회복할 수 있습니다. 새 게임과 이전 버전 최초 변환 시 몬스터볼 5개와 상처약 3개를 제공합니다.

## 육성·진화 규칙

- 시작 레벨 7. 부화 후보 42종 중 미뇽·이브이·메타몽은 각각 2%, 나머지 39종은 총 94%를 균등 배분하여 각각 약 2.4103%입니다. 이로치 추첨은 종 추첨과 별도입니다.
- HGSS 레벨업 기술과 4칸 제한을 유지합니다. 미뇽의 레벨 7 불꽃세례는 게임 전용 예외입니다.
- 3마리는 피로도 100을 공유합니다. 전투 +35, 밥 +15, 잠자면 다음 게임 날로 넘어가며 피로도가 초기화됩니다. 현실 날짜와 무관합니다.
- 전투 승리 시 활동 중인 친구에게 경험치 `floor((40 + 3 × 상대 레벨²) × 0.8)`, 지갑에 80 P가 들어옵니다. 다른 친구에게 경험치를 나눠주지 않습니다.
- 현재 출전한 친구가 기절하면 전투가 끝납니다. 기절하기 전에 교체할 수 있습니다. PP는 새 전투마다 회복되며 상태이상은 전투 안에서만 유지됩니다.
- 돌/교환 진화는 **상점에서 필요한 도구를 구매한 뒤** 성장 화면에서 사용합니다. NPC 교환은 같은 친구가 진화해서 돌아오는 방식입니다. 교환에 필요한 진화 도구는 전용 소비 아이템으로 처리하므로 전투용 지닌 도구 칸과 독립입니다.
- 친밀도 진화는 220 이상에서 레벨업입니다. 낮·밤과 신오 진화 여행지를 선택할 수 있습니다. 장소 진화는 HGSS에 없는 D/P/Pt 장소를 게임 안에 보완한 설정입니다.
- 놓아주기는 선택한 한 마리만 제거하고 지닌 도구를 가방에 돌려줍니다. 나머지 친구·포인트·가방·날짜·피로도는 유지합니다. 마지막 친구를 놓아주면 새 알을 받을 수 있습니다.

## 저장과 검증

저장은 브라우저 localStorage의 기존 `pokedays-hgss-v1` 키를 사용하며 구조 버전은 3입니다. 이전 구조 변환 전 원본은 `pokedays-hgss-v1-legacy-backup`에 보관합니다. 다른 기기·브라우저로 자동 동기화되지는 않습니다. 저장 파일 가져오기는 진행 중인 전투·학습 처리가 없는 백업을 지원합니다.

`npm test`: 63개 테스트 통과. 포획 공식, 세 마리 제한, 이로치 이미지, 저장 변환, 가방·도구 보존, 회복 턴, 기술 효과, 진화와 고오스 오류를 검사합니다. 브라우저에서 상점 구매·장착·회복·포획·선택을 확인했고 320/360/393/430/740px에서 HP창과 캐릭터 영역이 겹치지 않음을 확인했습니다.

## 데이터와 출처
