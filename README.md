알에서 만난 한 마리와 전투하고, 밥을 먹고, 잠을 자며 키우는 픽셀 웹 팬 게임입니다. 정적 HTML/CSS/JavaScript로 작동하며 실행 중 외부 API나 서버 키가 필요 없습니다.

총 27종입니다. 기존 15종을 유지하고, 현재 도감에 3단계 진화 계열이 모두 들어 있는 첫 형태 12종을 추가했습니다. 미뇽 5%, 이브이 5%, 나머지 25종 각각 3.6%입니다.

## 놓아주기

나의 단짝 아래 **놓아주고 새 알 받기** 버튼 또는 게임 안내의 동일 버튼을 누릅니다. 확인창에서 현재 저장을 백업하거나 취소할 수 있습니다.

확인하면 포켓몬·레벨·기술·포인트·날짜·피로도·진화 환경을 초기화하고 알 화면으로 돌아갑니다. 새 알을 클릭하면 다시 추첨합니다. 전투·기술 학습·진화 처리 중에는 놓아줄 수 없습니다.

업데이트 자체로 저장을 초기화하지 않습니다. 기존 포켓몬과 이전 버전의 저장 백업은 호환됩니다. 새 후보는 새로 부화하는 알부터 적용됩니다.

## 데이터 기준

- 4세대 하트골드·소울실버(HGSS)의 레벨업 기술표, 타입, 종족값, 기술 위력/명중/PP.
- 전체 160종, 373개 기술, 2,114개 레벨별 학습 기록, 앞/뒤 픽셀 이미지 320장.
- 기술머신·교배 기술은 제외. 기술은 최대 4개이며 새 기술은 교체하거나 배우지 않기를 선택합니다. 현재 종의 해당 레벨 이하 기술은 무료로 다시 떠올릴 수 있습니다.
- 한국어 도감 설명은 HGSS 번역 자료 부재로 X 버전을 사용하며 출처 버전을 표시합니다.
- **장소 진화는 같은 4세대 D/P/Pt의 조건을 지원합니다.** HGSS에는 해당 특수 장소가 없어 이 게임에 신오 진화 여행지를 별도로 구현했습니다. 최신 세대의 돌 진화 조건으로 바꾸지 않았습니다.
- 친밀도 진화는 4세대 기준 220 이상에서 레벨업입니다.

`data/pokedex.json`에 모든 포켓몬의 기술표·진화 목록·원본 URL·원본 CSV SHA-256 해시가 있습니다. 진화 레코드는 도구, 교환, 낮/밤, 공격/방어 비교, 장소와 특수 바위 조건 및 조건의 버전을 보관합니다.

## 신규 후보의 진화

| 시작 | 진화 조건 |
|---|---|
| 에레키드 | 레벨 30 → 에레브 → 에레키부스터를 지니고 교환 → 에레키블 |
| 코일 | 레벨 30 → 레어코일 → 천관산 특수 자기장에서 레벨업 → 자포코일 |

| 배루키 | 레벨 20 이상에서 공격 > 방어: 시라소몬 / 공격 < 방어: 홍수몬 / 공격 = 방어: 카포에라 |
| 이브이 | 물의돌 → 샤미드 / 천둥의돌 → 쥬피썬더 / 불꽃의돌 → 부스터 |

| 이브이 | 영원의숲 이끼 낀 바위 근처 레벨업 → 리피아 / 217번도로 얼음 바위 근처 레벨업 → 글레이시아 |

이브이는 4세대의 7개 진화형을 지원합니다. 님피아는 포함하지 않습니다. 기존 미뇽은 30레벨에 신뇽, 55레벨에 망나뇽으로 진화합니다.

### 게임 안에서 조건 맞추기

- **돌 진화**: 다음 성장에 표시된 원하는 진화형의 버튼을 누릅니다. 300 P로 돌을 구매하고 사용합니다.
- **교환 진화**: NPC 교환소에서 300 P로 필요한 도구를 준비하고, 지닌 채 교환한 뒤 진화한 같은 친구를 돌려받습니다. 도구는 소모됩니다. 실제 사용자 간 네트워크 교환은 아닙니다.
- **시간·장소 진화**: 다음 성장의 모험 시간(낮/밤), 진화 여행지를 선택한 후 레벨업합니다. 선택만으로 즉시 진화하지 않습니다. 현실 시간과 무관한 게임 내 환경입니다. 이브이는 바위 조건을 만족하면 친밀도 조건보다 바위 진화를 우선합니다.
- **배루키**: 부화할 때 공격·방어 개체값을 각각 0~31로 정합니다. 레벨업 후 실제 수치로 분기를 결정하며, 현재 공격/방어를 다음 성장에서 보여줍니다. 공격과 방어가 같은 종족값에 항상 묶여 카포에라만 되는 문제를 방지했습니다. 해당 두 개체값은 진화·저장·전투에도 이어집니다. 전투 중 일시적인 능력치 랭크나 상태이상은 진화 분기에 영향을 주지 않습니다.

## 육성과 전투

| 행동 | 변화 |
|---|---|
| 전투 | 피로 +35, 포만감 -18. 승리 경험치 `40 + 3 × 상대 레벨²`, 80 P |
| 밥먹기 | 피로 +15, 포만감 +35, 최대 HP 30% 회복, 친밀도 +12 |
| 잠자기 | 다음 게임 날, 피로 0, HP 회복, 포만감 -12, 친밀도 +3 |

피로는 100을 넘길 수 없습니다. 레벨업마다 친밀도 +5. 경험치는 종별 성장 곡선을 따릅니다. PP는 매 전투 시작에 회복하며 전투는 60턴이 지나면 무승부입니다.

상대는 전국도감 1~151에서 프리져·썬더·파이어·뮤츠·뮤를 제외한 146종입니다. 육성 후보가 늘어도 상대 목록은 유지됩니다. 상대 레벨은 내 친구보다 0~2 낮습니다. 3단계 계열은 중간형 20 이상, 최종형 36 이상에 등장하되 실제 진화 최소 레벨이 더 높으면 그 이후에 등장합니다. 2단계 계열은 36 이상에 최종형이 나옵니다. 1세대 내 진화 없는 종은 20 이상, 종족값 합계 450 이상이면 30 이상에 등장합니다. 자세한 구간은 JSON의 `encounter`에 있습니다. 이는 원작 야생 분포가 아닌 이 게임의 등장 정책입니다.

타입 상성은 4세대 17타입입니다. 복합 타입은 배율을 곱해 0·¼·½·1·2·4배를 적용합니다. 같은 타입 기술은 1.5배. 물리/특수는 해당 공격/방어 능력치를 사용합니다. 고정·조건부 피해에는 타입 무효만 적용하고 일반 배율을 곱하지 않습니다. 발버둥은 타입과 STAB를 무시합니다. 버튼과 피해 로그에 배율을 표시합니다.

원작 전투 엔진의 완전한 재현은 아닙니다. 특성·전투 도구·날씨·일부 변화기와 부가 효과를 간소화합니다. 배루키 계열의 공격/방어를 제외한 개체값은 0이며 노력치·성격·교배는 구현하지 않습니다. 메타몽은 HP/레벨을 유지하고 상대 타입·HP 외 능력치·기술을 복사하며 기술별 PP는 5입니다.

## GitHub Pages 업데이트

압축 안 `pokemon-days-balance-update` 폴더 **안의 파일과 폴더**를 기존 저장소 최상위에 덮어씁니다. GitHub Desktop에서 Commit → Push origin을 누르고, Pages 배포 완료 후 Ctrl+F5로 새로고침하세요. ZIP 자체를 올리지 않습니다. `index.html`, `app.js`, `engine.js`, `style.css`, `data/`, `assets/`가 같은 위치에 있어야 합니다.

처음 배포한다면 Settings → Pages → Deploy from a branch → main / (root) → Save. 기존 Pages 설정이 docs/라면 그 폴더 안에 덮어씁니다. 이미지 파일이 많으므로 GitHub Desktop을 권장합니다. 웹 업로드는 한 번에 100개 이하로 나눠야 합니다.
