# POKÉ DAYS

알에서 무작위로 만난 한 마리의 포켓몬을 기르는 픽셀 웹 팬 게임입니다. 프레임워크나 서버 API 키 없이 HTML/CSS/JavaScript로 작동합니다.

## 실제 데이터의 범위

- 시작 포켓몬: 미뇽(1%), 피카츄, 파이리, 이상해씨, 꼬부기, 디그다, 나옹, 뽀뽀라, 푸푸린, 삐.
- 야생 상대 146종, 육성용 아기 포켓몬 포함 전체 149종, 369개 기술, 1,964개 레벨별 습득 기록.
- 규칙 기준: **하트골드·소울실버, 4세대**. 레벨업 기술만 포함합니다.
- 이름·도감번호·진화 레벨·진화의돌·친밀도 조건·기술 습득 레벨은 수집한 실제 데이터를 따릅니다.
- 타입·종족값·기술 위력/명중/PP는 PokeAPI 과거 변경 내역을 적용합니다.
- 한국어 도감 설명은 데이터베이스에 HGSS 번역이 없어 **X 버전** 설명을 사용하며 화면에 출처 버전을 표시합니다.
- 친밀도 진화는 4세대 기준 **220 이상에서 레벨업**입니다. 최신 데이터의 160을 그대로 사용하지 않습니다.
- 현재 보유 기술은 최대 **4개**. 새 기술을 배우려면 빈 칸에 넣거나 기존 기술을 교체하며, 학습을 건너뛸 수도 있습니다.

`data/pokedex.json`에는 정규화한 도감·기술·진화·경험치·타입 상성과 원본 URL 및 SHA-256 해시가 들어 있습니다. 게임은 이 파일을 읽습니다. 실행 중 외부 API를 호출하지 않습니다.

## 게임 고유 규칙

| 행동 | 변화 |
|---|---|
| 전투 | 피로 +35, 포만감 −18. 승리하면 80 P와 `40 + 3 × 상대 레벨²` 경험치 |
| 밥먹기 | 피로 +15, 포만감 +35, 최대 HP의 30% 회복, 친밀도 +12 |
| 잠자기 | 다음 게임 날, 피로 0, 친구 HP 회복, 포만감 −12, 친밀도 +3 |

- 실제 날짜와 무관한 게임 속 하루입니다. 잠자기로 다음 날을 시작합니다.
- 알을 클릭하면 미뇽이 1%, 기존 9종이 각각 11% 확률로 부화하며, 그 친구만 레벨 10부터 키웁니다. 초기 기술은 해당 레벨 이하의 실제 학습 기술에서 최대 4개를 선택하며, 전투 가능한 공격 기술을 하나 유지합니다.
- 다른 포켓몬으로 교체할 수 없습니다. 부화 결과는 애니메이션 전에 저장해 새로고침이나 연속 클릭으로 재추첨하지 않습니다.
- 레벨업마다 친밀도 +5. 경험치 필요량은 원래 성장 곡선을 사용합니다.
- 진화의돌은 300 P를 사용해 구매와 사용을 동시에 진행합니다. 확인 후 진화합니다.
- 현재 종이 해당 레벨 이하에서 배울 수 있는 기술을 무료로 다시 떠올릴 수 있습니다.
- 특성·도구·교배·개체값·노력치·성격은 구현하지 않습니다. 종족값을 기반으로 능력치를 계산합니다.
- 1:1 턴제 전투는 타입 상성, 물리/특수, 명중, PP, 기본 상태이상 등을 반영합니다. 날씨·교체·일부 변화기/부가 효과는 간소화되며 게임 안에서 안내합니다. 원작 전투 엔진의 완전 재현은 아닙니다.
- PP는 매 전투 시작 시 회복하며, 60턴이 지나면 무승부로 종료합니다.
- 저장은 이 브라우저의 localStorage에 보관됩니다. 기기 간 동기화는 없습니다. 전투와 학습 선택도 저장되며 새로고침 후 이어집니다.
- 게임 안내에서 JSON 백업을 가져올 수 있습니다. 가져오기 전 현재 진행 상황을 덮어쓸지 확인합니다.

## 로컬 실행

이 게임은 ES modules와 JSON fetch를 사용하므로 파일을 더블클릭하는 대신 정적 서버로 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속하세요. Python이 없다면 VS Code Live Server 같은 정적 서버를 사용할 수 있습니다.

## GitHub Pages

`index.html`, `app.js`, `engine.js`, `style.css`, `data/`, `assets/`가 같은 최상위에 있어야 합니다.
저장소 Settings → Pages → Deploy from a branch → main → /(root) → Save.

## 데이터 갱신

Python 3 표준 라이브러리만 사용합니다. PokeAPI CSV를 `.data-cache`에 캐시합니다.

```bash
python scripts/fetch_data.py
python scripts/build_snapshot.py
python scripts/fetch_sprites.py
```

데이터셋 갱신 후 테스트를 실행하세요. 원격 데이터가 변경될 수 있으므로 배포된 JSON의 수집 시점과 파일 해시를 확인할 수 있습니다.

## 알 부화 업데이트

첫 시작은 알 화면입니다. 기존 버전 저장은 당시 활성 포켓몬의 레벨·기술·진화·피로와 진행 상황을 유지한 채 1마리 육성으로 전환됩니다. 이전 원본 저장은 브라우저 내 별도 백업 키에 보관합니다. 새 알을 만나려면 게임 안내 → 새 알로 시작하기를 선택하고 초기화를 확인하세요. 현재 저장을 다운로드한 뒤 초기화할 수도 있습니다.


## 1세대 상대 · 상성 패치

- 전국도감 1~151번 중 프리져(144), 썬더(145), 파이어(146), 뮤츠(150), 뮤(151)를 제외한 **146종**이 야생 상대입니다. 지역 변종은 포함하지 않습니다.
- 알 부화와 한 마리 육성, 저장 키, 진화와 기술 데이터는 유지됩니다. 새 게임을 시작할 필요 없이 다음 전투부터 적용됩니다. 이미 진행 중인 전투의 상대는 유지됩니다.
- 상대 레벨은 친구보다 0~2 낮습니다. 각 상대 레벨에서 등장 가능한 종을 동일 확률로 선택합니다.
- **상대 등장 규칙은 게임 고유 밸런스입니다.** 1세대에 존재하는 진화 계열만으로 단계를 계산합니다. 이후 세대의 아기 포켓몬이나 진화형은 상대 단계를 바꾸지 않습니다.

| 계열 | 등장 구간 (상대 레벨) |
|---|---|
| 3단계 진화 | 미진화형 → 20 이상 중간형 → 36 이상 최종형 |
| 2단계 진화 | 미진화형 → 36 이상 최종형 (중간형 없음) |
| 늦게 진화하는 종 | 실제 최소 진화 레벨 이후. 신뇽 30, 망나뇽 55부터 |
| 돌·교환 진화 | 위 단계별 등장 구간 적용. 육성 중 돌 진화 조건은 유지 |
| 1세대 내 진화 없는 종 | 20부터. 종족값 합계 450 이상이면 30부터 |

각 단계는 다음 단계가 등장하기 전까지 유지됩니다. 예를 들어 파이리 1~19, 리자드 20~35, 리자몽 36~100이며, 미뇽 1~29, 신뇽 30~54, 망나뇽 55~100입니다. 원작의 야생 분포나 원작 진화 시점을 변경한 것이 아니라 이 게임의 상대 선택 범위입니다. 상세 구간은 각 JSON 포켓몬의 `encounter`에 저장했습니다.

기존 타입 상성과 STAB 계산을 재검증하고, 발버둥 예외를 수정했습니다. 전투 버튼에 **상성 배율**과 **같은 타입 1.5배**를 표시하고, 상대 HP 카드에 타입을 표시합니다. 물리/특수 공격은 각각 공격/방어와 특수공격/특수방어를 사용합니다. 복합 타입은 배율을 곱하여 0, 0.25, 0.5, 1, 2, 4배가 됩니다. 고정·조건부 피해 기술은 무효 타입을 제외하고 상성 배율과 STAB를 적용하지 않습니다. 발버둥은 타입과 STAB를 무시합니다.

타입 표는 HGSS 4세대 17타입으로 고정합니다. 페어리는 없고, 강철은 고스트·악을 반감합니다. 공식 배틀 가이드는 공통 원리(복합 타입, STAB, 물리/특수)의 근거로 사용하며, 최신작 타입 표를 그대로 복사하지 않습니다. 메타몽은 변신으로 상대 타입·HP 외 능력치·기술을 복사하며 기술마다 PP 5를 받습니다. 특성, 도구, 날씨 및 일부 기술 부가 효과 등 기존 전투 간소화 범위는 유지됩니다.

## v1.3 — 희귀 미뇽 알

- 미뇽 1%, 기존 9종 각각 11%. 총 100%이며 각 새 게임의 부화는 독립 추첨입니다. 100번 중 반드시 한 번 나온다는 보장은 아닙니다.
- 미뇽도 레벨 10부터 한 마리만 키웁니다. HGSS 실제 기술과 최대 4칸을 유지하며, 레벨 30에 신뇽, 레벨 55에 망나뇽으로 진화할 수 있습니다.
- 희귀 부화 화면에 `RARE FRIEND · 1%`를 표시합니다. 추첨 결과는 애니메이션 전에 저장하므로 연속 클릭이나 새로고침으로 바뀌지 않습니다.
- 기존 저장은 유지됩니다. 새 확률을 적용하려면 게임 안내에서 현재 저장을 백업한 뒤 새 알로 시작하세요. 아직 부화하지 않은 저장은 그대로 새 확률을 사용합니다.
- 확률은 `data/pokedex.json`의 `hatchTable`에 저장하며, 데이터 재생성 스크립트에도 동일하게 반영했습니다. `legacyStarterIds`는 예전 9마리 저장 형식을 복원하기 위한 목록입니다.
- 24개 엔진 테스트 통과. 이번 추가 검증은 확률 경계/분배와 미뇽의 진화/저장 복원입니다.
